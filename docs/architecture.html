InfoMentor MCP — Server Architecture

A host-neutral MCP server for typed, direct HTTPS access to Swedish InfoMentor parent data

Host-neutral

Any compatible MCP host can start the server over standard stdio. The diagram intentionally does not depend on a specific client, desktop app, agent, or orchestration platform.

Typed and scoped

Tools validate inputs and provider responses. School records are read-only except for the two explicit fritidsschema write tools, both of which require exact read-back verification.

Protected by default

Credentials and sessions stay in host-provided or local protected state. Secrets never travel through tool arguments, structured results, logs, or the repository.
